# 教師帳號怎麼登入

楊梅高中教師帳號說明頁。三組密碼分別用在哪些服務、忘記帳號密碼怎麼辦、常見狀況怎麼處理。

**線上版：** https://hmjvaliney.github.io/ymhs-account-guide/

## 這一頁在解決什麼問題

老師手上有三組**互不相通**的帳號密碼：

| | 來源 | 用在 |
|---|---|---|
| 第 1 組 | 校內 AD | 辦公室電腦、校內無線網路、Microsoft 365 `@ymhs.tyc.edu.tw` |
| 第 2 組 | 桃園市校園單一認證 | 教育資源入口網、Google `@ms.tyc.edu.tw`、Microsoft 365 `@o365.tyc.edu.tw`、Adobe |
| 第 3 組 | 教育部教育雲端帳號 `@sso.edu.tw` | 教育部信箱、Google `@go.edu.tw`、Microsoft 365 `@ms.edu.tw`、在職進修網，及 47 個介接服務 |

最常見的三種求助都來自誤以為只有一組密碼：

1. 改了電腦密碼 → 手機平板連不上校內 WiFi（帳密存在裝置裡，要逐台重設）
2. 改了電腦密碼 → 學校 Google 進不去（那是獨立的一組密碼）
3. 改了市網密碼 → `@ms.tyc.edu.tw` 的 Google 進不去（要回認證平台手動同步）

## 內容

單一檔案 `index.html`，無建置流程、無外部依賴（僅載入 Google Fonts）。內建 58 項服務的搜尋查詢，支援深色模式與手機版面。

- 教育部介接服務清單由教育部維護，會隨介接進度增減：<https://www.sso.edu.tw/splist>（本頁擷取於 2026-09-02，共 51 項）
- 市級與部級系統的登入方式由主管機關決定，可能隨其系統改版而變動

修改 `index.html` 後推送到 `main`，GitHub Pages 會自動更新。
